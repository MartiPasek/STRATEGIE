📧 Připojit poštovní schránku

Připoj svou firemní e-mailovou schránku, aby z ní systém mohl posílat e-maily tvým jménem (např. hromadné oslovení v CRM). Heslo se uloží šifrovaně a posílá se přímo na server — neprochází přes žádnou AI.

Tvůj login do firemní pošty (ví IT — nemusí být stejný jako adresa níže).
Adresa, která se příjemcům ukáže jako „From".
🔒 Heslo nikdo z týmu ani žádná AI nevidí — uloží se zašifrované a použije se jen pro odesílání z tvé schránky.
