⬆ Import z výkazu práce

Z výkazů (EUROSOFT Work Report — list „Stunden") založí docházku stejně jako „Makat": přítomnost + pauzu (→ mzda) i úsek na zakázce (→ zakázky). Pracovník se páruje podle čísla zaměstnance (buňka G5). Den 06:00–14:30 s pauzou 0,5 = 8 h práce + 0,5 h pauza. Nejdřív uvidíš náhled, teprve pak potvrdíš zápis.
