Jak to čte STEP7 hlava: krok drží akci (= „přispěj touhle částí promptu") a svou vrstvu pečení. Přechod je tranzice s podmínkou — prázdná = jde se rovnou dál; s obsahem = rozhodovací/přechodová podmínka (větvení, i paralelní větve). Běh grafu = projdi kroky podle podmínek → složený prompt je posloupnost jejich částí. Verze grafu = zápisníček, do kterého se dá vracet a hrát si.
Otevřené k odrazu: Je „podmínka" text/pravidlo, nebo malý výraz nad daty (např. user_id != null)? · Potřebujeme paralelní větve (víc částí naráz) hned, nebo stačí sekvence + větvení? · Denní vrstva = vlastnost kroku, nebo vlastní ranní běh?
