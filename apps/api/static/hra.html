Jak Claude hraje účetnictví 🧩

Helios je „klíč odpovědí". Claude bere doklad po dokladu, zkusí ho zaúčtovat po našem a porovná s Heliosem. Kde se shodnou = uhráno. Kde ne = hádanka, kterou doladí v pravidlech. Cesta od 0 % ke 100 % — autonomně, jen pár věcí zbude na člověka.
