🏢 Organigram
Organizační schéma z kompetenční struktury firmy (posty a jejich držitelé). Jen ke čtení. Jeden člověk může mít víc postů a jeden post víc lidí.
📌 Zdroj: organizační struktura firmy (posty + přiřazení osob), tzn. kompetenční model ISO.

📑 Podmínky zaměstnanců
