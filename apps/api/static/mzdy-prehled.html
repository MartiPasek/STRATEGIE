Účetní pohled na mzdy — měsíční náklady, odvody a čistá mzda z účetního deníku.

Jak to čteme: Hrubé mzdy = účet 521 (mzdové náklady), pojištění zaměstnavatele = 524 (SP+ZP 33,8 % nad hrubou), ostatní soc. náklady = 527. Součet = mzdové náklady firmy. Odvody SP+ZP = 336 (sražené zaměstnanci + zaměstnavatel, jde na ČSSZ a zdravotní pojišťovny), daň = 342 (záloha daně ze závislé činnosti na FÚ), závazky 331 = připsáno zaměstnancům k výplatě (hrubá mzda + náhrady; čistá výplata = 331 − sražené odvody zaměstnance − daň).
