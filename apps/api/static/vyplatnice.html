🧾 Výplatnice přímo z Helios výpočtu

Spočítané mzdy čtené z Helios cloud (TabZamVyp). Helios počítá legislativu, my zobrazujeme.

Vyber firmu/období a načti…
Pokud jsou částky nulové nebo staré, spusť v Heliosu Mzdy → Výpočet mzdy → Akce → Výpočet — Helios přepočítá z předzpracování a zde se objeví aktuální čísla. Aktivní lidé do období se řídí z našeho systému (MOST · Mzdy_Vstup).
