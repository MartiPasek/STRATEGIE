# 1. Účel

Dokument stanovuje měřitelné cíle bezpečnosti informací dle ČSN EN ISO/IEC 27001:2022 (kap. 6.2). Plnění vyhodnocuje manažer ISMS a předkládá při přezkoumání vedením (DOC-17).

# 2. Cíle a metriky

| Cíl | Metrika a cílová hodnota | Frekvence | Odpovědný |

| Žádné neošetřené významné riziko | Počet rizik ≥15 bez opatření/akceptace = 0 | Čtvrtletně | Manažer ISMS |

| Vícefaktorové ověření přístupů | Podíl účtů s MFA = 100 % | Čtvrtletně | Správa IT |

| Spolehlivé zálohy a obnova | Denní záloha (03:00); úspěšný test obnovy ≥ 1×/měsíc | Měsíčně | Správa IT |

| Včasná reakce na incident | Kritický incident podchycen do 4 h od zjištění | Dle výskytu | Manažer ISMS |

| Řízené přístupy lidí | Onboarding/offboarding do 24 h = 100 % | Průběžně | HR + Správa IT |

| Pravidelná kontrola ISMS | Interní audit a přezkoumání vedením ≥ 1×/rok | Ročně | Manažer ISMS |

| Bezpečnostní povědomí | Poučení 100 % zaměstnanců ≥ 1×/rok | Ročně | HR |

| Správa zranitelností | Kritické zranitelnosti opraveny do 1 dne (v rámci dne) | Měsíčně | Správa IT |

# 3. Vyhodnocování

Cíle se vyhodnocují ve stanovené frekvenci. Nesplnění se řeší jako podnět ke zlepšení, případně neshoda (DOC-18). Cíle se aktualizují nejméně jednou ročně.
