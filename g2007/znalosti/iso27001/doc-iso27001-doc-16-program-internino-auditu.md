# 1. Účel a rozsah

Program zajišťuje pravidelné nezávislé ověření shody a účinnosti ISMS dle ČSN EN ISO/IEC 27001:2022 (kap. 9.2).

# 2. Zásady

Frekvence — nejméně jednou ročně, pokryje všechny oblasti ISMS.

Nezávislost — auditor neposuzuje vlastní práci; lze využít externího auditora.

První interní audit proběhne do 14 dnů od schválení dokumentace (cca 1. 7. 2026).

Objektivita — zjištění se opírají o důkazy (záznamy, audit log, rozhovory).

# 3. Plán auditu

| Oblast | Co se ověřuje | Termín |

| Řízení ISMS | Politika, rozhodnutí, cíle, dokumentace | do 14 dnů |

| Rizika a SoA | Registr rizik, plán ošetření, SoA | do 14 dnů |

| Přístupy a provoz | Přístupy, zálohy, logy, incidenty | do 14 dnů |

| Lidé a dodavatelé | Školení, onboarding/offboarding, dodavatelé | do 14 dnů |

# 4. Průběh a výstup

Příprava — plán a kritéria.

Provedení — sběr důkazů, posouzení shody.

Zpráva — zjištění (shoda / neshoda / podnět).

Neshody se řeší dle DOC-18; výsledky jsou vstupem do DOC-17.

# 5. Záznamy

Z každého auditu se pořizuje zpráva (rozsah, zjištění, neshody, doporučení) a uchovává jako důkaz o fungování ISMS.
