# Kalkulace Cenotvorba

> oblast: `kalkulace-rozvadecu` · úroveň: obor · typ: dokument · verze: V1.0 · rozsah: globální (všichni tenanti)

**Finální cena = lidský cit, engine dává jen náklad; materiál něm. + ČR marže**

Kalkulační engine (tenant.kalk_*, /kalkulace, @@KALKSYNC/CALC/STD) oživen z Martiho systému z DB_Ceniky (2014): CC (výrobní náklad) × rabat → cena; koeficient → VKM/Arbeit (práce).
CENOTVORBA (Martiho princip): finální cena = LIDSKÝ CIT, ne jen vzorec. Engine dává jen NÁKLAD (materiál + práce); finální cena je obchodní rozhodnutí člověka. Materiál = často německá výroba (dražší) + česká marže; práce = hodinová sazba. Cílový zákazník: střední firmy ~30–300 lidí. (Member-veřejné.)
