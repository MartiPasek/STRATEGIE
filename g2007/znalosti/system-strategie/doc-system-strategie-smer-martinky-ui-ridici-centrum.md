# SMER UI (Marti 3.8.2026): Ridici centrum = uchopeni pres Firmu/dochazku - skupiny -> lide -> jejich AI tymy

> oblast: `system-strategie` · úroveň: obor · typ: dokument · verze: V1.0 · rozsah: globální (všichni tenanti)


## Zavazny smer UI od Marti (3.8.2026, iterovano nad mockupy v1-v3)

UI je klicova problematika, pristupovat zodpovedne: MOCKUPY -> pripominky (Marti+Kristy+Eliska) -> stavba. Obe tvare (mobil + ERP) nad JEDNOU spolecnou API vrstvou (existujici martinka_* skripty pres /run) - UI je jen ctecka nad tekoucimi daty, zadna nova datova vrstva.

## Uchopeni: OD LIDI, vzorem je dochazka/pritomnost
Vstupni obrazovka mobilu = "Firma" jak ji lide znaji z dochazky: SKUPINY (strom dochazkovych skupin, bezi od 24.7.) -> LIDE s pritomnosti (makam od / dovolena) -> a NOVE kazdy clovek nese svuj AI tym: badge "N ceka" / "klid".

## Hierarchie prokliku (schvalena posloupnost, mockup v3)
1. FIRMA: skupiny (Vedeni, VP, Vyroba, ISO...) -> lide + pritomnost + AI badge.
2. CLOVEK: nahore jeho CHAT S MAMINKOU (konverzace "🌸 Moje Martinky" - ranni souhrn, navrhy, dotazy), pod tim jeho MARTINKY jako karty (fronta, stav automatu-oci, co ceka).
3. MARTINKA: jeji ukoly (stavy).
4. UKOL: cele VLAKNO = jeden pribeh (zadani cloveka, prideleni Maminky se zduvodnenim, nastrojova volani, vysledek Martinky, chat) + akce Schvalit/Vratit/Napsat.

## Prava (rozhodnuto): vlastnik vidi a ridi sve, rodice vse (vc. metrik/spotreby). Skupinova viditelnost dle prav dochazky.
## Poradi (rozhodnuto): MOBIL prvni (Priorita 1 - uridit sami sebe; Eliska+Kristy ziji v mobilu; nasazeni az po vecerni oprave fragmentu mobile.html), ERP koordinacni prehled (fronty per clovek, katalog Martinek s profily, zivy proud, zdravi systemu, metrika "% prideleni bez zasahu") pote.
## Lide bez Martinek (Peta, Misa...): zobrazovat od zacatku s "AI: zatim bez Martinek" - struktura zve k rustu.
